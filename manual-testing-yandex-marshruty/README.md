# Проект: Тестирование Яндекс Маршруты (веб)

**Сервис:** веб‑версия Яндекс Маршрутов — построение маршрутов для разных видов транспорта, расчёт стоимости, бронирование.

## Цель проекта

Провести функциональное и кроссбраузерное тестирование ключевых пользовательских сценариев, подтвердить соответствие реализации требованиям и макетам, выявить дефекты и оформить тестовую документацию.

## Что было протестировано

- **Валидация полей:** проверка обязательных полей, форматов ввода, сообщений об ошибках.
- **Расчёт стоимости:** корректность расчёта для разных типов транспорта и сценариев.
- **Логика окон оплаты:** переходы между шагами, сохранение данных, обработка ошибок.
- **Кнопка «Забронировать»:** проверка срабатывания, валидация перед отправкой, обработка состояний (активна/неактивна).

## Кроссбраузерность

Тестирование выполнено в браузерах:
- Яндекс Браузер
- Firefox

Проверены различия в отображении и поведении элементов.

## Подход к тестированию

- **Декомпозиция требований:** требования разбиты на атомарные проверки для покрытия всех веток логики.
- **Сверка с макетами в Figma:** визуальное соответствие, отступы, состояния элементов (hover, focus, disabled).
- **Техники тест‑дизайна:** классы эквивалентности и граничные значения для полей ввода; таблицы принятия решений для сценариев оплаты.

## Артефакты проекта

В репозитории представлены:
- Чек‑листы — быстрый регресс по ключевым модулям.
- Тест‑кейсы — подробные сценарии с шагами и ожидаемыми результатами.
- Баг‑репорты — задокументированные дефекты с шагами воспроизведения.

## Инструменты и стек

## Мои выводы и польза проекта

Проект позволил отработать полный цикл ручного тестирования: от декомпозиции требований до формирования отчётности. 
Выявленные дефекты помогли улучшить UX и снизить риски на проде. 
Особенно ценным был опыт кроссбраузерной проверки.
