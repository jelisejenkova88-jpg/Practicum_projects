# Проект: Тестирование Яндекс Метро (мобильное приложение)

**Сервис:** Яндекс Метро — мобильное приложение для навигации в метрополитене: интерактивная схема, построение маршрутов, выбор станций.
**Контекст:** команда провела рефакторинг кода Android‑приложения. Задача — подтвердить готовность новой версии к публикации в сторе.

## Цель проекта

Провести функциональное и регрессионное тестирование ключевых сценариев мобильного приложения, выявить дефекты и оформить тестовую документацию.

## Что было протестировано

### Маршрутизация
- Построение маршрутов между станциями.
- Выбор станции через поиск, через интерактивную схему, через список.

### Нативные функции
- **Офлайн-режим:** работа приложения без сети
- **Ориентация экрана:** портрет/ландшафт, сохранение состояния при повороте.
- **Миграция данных при обновлении:** сохранение пользовательских данных (избранные станции, история) после перехода на новую версию.

## Подход к тестированию

- **Декомпозиция требований:** требования разбиты на атомарные проверки, выявлены серые зоны — сценарии, не покрытые требованиями, для которых сформированы вопросы к команде.
- **Регрессионное тестирование:** проверка ранее работающего функционала после изменений, чтобы исключить побочные дефекты.
- **Тестирование на эмуляторах:** Android Studio
