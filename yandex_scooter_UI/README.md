# Sprint_6

# Автотесты для сервиса «Самокат»

Набор UI-автотестов для проверки ключевых сценариев сервиса «Самокат» (оформление заказа, FAQ, навигация).  
Реализовано по паттерну **Page Object Model**, используется **pytest**, **Selenium**, браузер **Firefox**. Отчёты формируются в **Allure**.

## Покрытые сценарии

- Оформление заказа (полный позитивный флоу) с проверкой двух точек входа: кнопки «Заказать» вверху и внизу страницы.
- Проверка FAQ: раскрытие вопросов и валидация текстов ответов (параметризованные тесты).
- Базовые проверки навигации по логотипам («Самокат», «Яндекс»).
- Тесты прогоняются с разными наборами тестовых данных для проверки устойчивости флоу.

## Особенности реализации

- **Page Object Model**: все действия вынесены в классы в папке `pages/`.
- **BasePage**: содержит общие методы ожидания, скролла и взаимодействия с элементами.
- **Параметризация**: используется `@pytest.mark.parametrize` с понятными `ids` для читаемости отчётов.
- **Allure**: шаги формируются через `@allure.step` в методах PageObject; заголовки тестов — через `@allure.title` и описание тестов через `@allure.description`.

## Реализованные тесты

- **`test_faq_question_opens_and_shows_correct_answer`**: параметризованный тест для проверки FAQ — для каждого вопроса проверяется раскрытие ответа и соответствие текста ожидаемому.
- **`test_order_via_top_button`**: параметризованный тест для проверки оформления заказа через кнопку "Заказать" в шапке и появления всплывающего окна об успешном заказе.
- **`test_order_via_bottom_button`**: параметризованный тест для проверки оформления заказа через кнопку "Заказать" внизу страницы и появления всплывающего окна об успешном заказе.
- **`test_click_scooter_logo`**: тест для проверки перехода на главную станицу после клика по логотипу 'Самокат'.
- **`test_click_yandex_logo`**: тест для проверки перехода на станицу Дзена после клика по логотипу 'Яндекс'.

## Требования и запуск

**Требования:**
- Python 3.13
- Firefox
- Зависимости из `requirements.txt`

**Запуск:**
pytest
pytest --alluredir=./allure-results
allure serve ./allure-results
